# 📸 DiVinti Studio — Portfólio Responsivo

Projeto prático desenvolvido durante o curso técnico para aplicar conceitos de **Design Responsivo**, utilizando **CSS Grid Flexível** e **Media Queries** com a identidade visual da marca fictícia **DiVinti** (preto, vermelho e branco).

🔗 **[Acesse o site online aqui](https://johndimitry.github.io)**

---

## 🎯 Objetivo do Projeto

Criar uma interface moderna que se adapta automaticamente a diferentes tamanhos de tela (Desktop, Tablet e Smartphone), garantindo boa legibilidade, navegação intuitiva e organização visual.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica (`header`, `nav`, `main`, `section`, `footer`).
* **CSS3:** Estilização customizada com paleta de alto contraste (`#0d0d0d`, `#e60023` e `#ffffff`).
* **CSS Grid Layout:** Organização flexível da galeria de fotos (`grid-template-columns`).
* **Media Queries:** Quebras de layout para telas de até `1024px` (tablets) e `768px` (smartphones).

---

## 📱 Comportamento Responsivo

* **Desktop (`> 1024px`):** Menu de navegação horizontal e galeria exibida em **4 colunas**.
* **Tablet (`769px` a `1024px`):** Menu reorganizado em lista vertical e galeria ajustada para **2 colunas**.
* **Smartphone (`≤ 768px`):** Cabeçalho centralizado e galeria exibida em **1 coluna única**.
